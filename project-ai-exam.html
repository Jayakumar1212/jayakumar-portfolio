AI Exam Companion

AI-Powered Study Assistant

The Problem

Students often struggle with organizing study materials and testing their knowledge effectively before exams. Traditional study methods can be disjointed and lack personalized feedback.

My Role & Approach

I designed and built a full-stack application to provide an interactive study experience.

  • Frontend: Developed a responsive and intuitive UI using React.js.
  • Backend & Database: Utilized Firebase for real-time data synchronization and user authentication.
  • AI Integration: Implemented a Node.js API to interface with AI models for generating quiz questions and providing content summaries.

Key Features

  • Personalized Quiz Generation
  • Progress Tracking & Analytics
  • Real-time Study Sessions

Tech Stack

React Firebase Node.js
